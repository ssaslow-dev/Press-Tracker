# AJG Press Tracker

Code, tests and decision records for the press-coverage tracker of CA Assemblymember Jesse Gabriel (AD-46).

- `docs/START_HERE.md`: where to begin. `docs/DECISIONS.md` is the decision log; `docs/HANDOFF.md` covers operations.
- `code/`: the tracker page sources (`code/tracker/`), the save pipeline (`sheet_task.py` and its rule modules) and reference data.
- `build/`: build scripts and test suites (`build/tests/run_all.sh`).
- `work/saver/`: the save program in progress (rules in `SAVE_RULES.md`, spec in `SAVER_SPEC.md`).
- `work/update_review/`: the Update-button review (REPORT.md); `work/localapp/`: the new tracker (PLAN.md).

Not in this repository: the master workbook and the article library. They stay on Sammy's Mac until a storage decision is made.
