# reporters — Reporter outreach list (Insights feature 4, agent-ins-reporters)
- Shows: one card, "Reporter outreach list": 1,285 reporters ranked by stories; columns Reporter, Outlets (2 shown + "+N more", full list on hover), Stories, Top issues (3), Avg tone (dot + label + signed mean), Last story, Reach. Search box (name/outlet/issue/reach), sortable headers (a "Sort" select replaces them under 760px, where rows stack as cards), first 100 rows + "Show all". Download CSV (the one .btn.primary) = rows currently shown, via ctx.saveFile + ctx.csv.
- Clicks: name / row -> Clips filtered by that author (ctx.clips({author})); last-story date -> story panel (ctx.openStory). params.author -> that row highlighted (.hl), "Show all" opened if needed, scrolled into view once.
- Data: ctx.D only — no data block, no _data.py.
- Rules: people only = ctx.authorKind(a) === 'person' (staff/board/wire/org out); same person = ctx.authorKey + ctx.canonAuthors (build_data already applied author_canon.csv); Jesse Gabriel and 'Op-ed by Gabriel' stories excluded (co-authors there are officials); stories = Originals; issues skip blank/'Unassigned'; tone mean Very negative -2..Very positive +2 over rated stories (label: >=1.5 Very positive, >=0.5 Positive, >-0.5 Neutral, >-1.5 Negative); Reach = tags over their stories, most first.
- Found: when a story's authors[] is empty the page falls back to the raw byline, so title-only bylines (Contributor x13, Contributing Editor x4, Staff Writer x2, 3 'Special to …') become "authors" with default kind 'person' in the tracker (they appear in its Reporter filter too). This view skips any author equal to the story's atitle. Shell-side fix suggestion: don't fall back to splitAuthors(r.author) when r.atitle === r.author.
