# REQ-3 verify() covers every tab

Patch: `patches/REQ-3_verify_tabs.patch` (`code/sheet_task.py` + one line added to `build/tests/run_all.sh`; applies cleanly, dry-run checked). Test: `patches/tests/test_verify_tabs.py` (copy in `REQ-3/`).

## Implementation (`verify_tabs(before_path, after_path, res)`, called from `verify()`; problems appended; return gains `tabs_checked`; cap 50 via VT_MAX)
- Reads each tab once with openpyxl read-only (values, `data_only=False`), skipping Coverage and Originals. Sheet names: every before sheet must exist after, sheets added are reported, order compared with Originals excluded. Header rows must be identical (trailing blanks ignored).
- Key per tab: Article ID (Audio & video details, Removed, Unlinked print pages); Release ID else URL (Press releases); tabs with no named key (Bills) use the first four columns together, because Bills' first column is not unique (266 distinct of 1,895 rows; the first four columns are unique) - deviation from "first column"; duplicates, if any, are numbered in order. Missing key after -> problem, except an Audio & video details key in `res['removed'][*]['rows'][*]['aid']`.
- Every non-blank before cell must equal the after cell (`norm_val`). Exempt: the 14 Press releases derived columns you listed. `res['related_cols']` is a statistics dict (counts, no cell list), so "related_cols-touched cells" cannot be enumerated; the derived-column exemption covers Related count / Related story IDs. New rows allowed only on Press releases, Audio & video details, Removed; elsewhere reported.
- Hyperlinks: counted per tab from the sheet XML (`<hyperlink` elements, via zipfile; read-only openpyxl does not expose hyperlinks and a full load is heavy); a drop is reported as `<tab>: hyperlinks dropped 3 -> 2`. Counts are per tab, not restricted to the key/URL column.
