# Blind audit of "AJG Tracker - User Guide.pdf" (38 pages), round 2

Audited 2026-11-05 by Fable from the PDF (every page rendered at 110 dpi, close checks at 200 dpi), the NewsBank Download Guide as the style standard, the companion guide "Updating the tracker with the Update station" (18 pages, final), and the version 4.3 program sources (`panel.js`, `plain.py`, `launcher.py`, `install_update.py`, the start and READ ME files for Windows and Mac, patch 33). Nothing was edited.

Print sizes below are worked out from each screenshot's print resolution (`pdfimages -list`) and the app's font sizes, and spot-checked at 200 dpi.

**Verdict:** Close to ready and a clear improvement on round 1, but not printable yet: three things it says about the program are no longer true in 4.3, its advice on the "older workbook" warning contradicts the companion guide, a new colleague's first copy and the office-PC block on the Update station are not covered, and about a dozen pages are more than half blank. One revision pass fixes all of it.

## Recommendations, most important first

1. **Page 28 and page 2: "Conflicts left for Sammy" is stale.** In 4.3 the save says "N conflicts left for the keeper to decide" (patch 33); it no longer names a person. The phrase the callout quotes does not appear in any screenshot on the page either, so the reader is told to expect words that never show up. Change: delete the callout on page 28. In the Keeper row on page 2, delete "Some program messages name Sammy; they mean the keeper." If a note is still wanted, add one line under the "Cells where the update disagrees with the workbook" row of the page 29 table: "The bold line counts these as 'conflicts left for the keeper to decide'." That is also the phrase the companion guide uses (its page 13).

2. **Page 27 step 4 and page 37: the "older workbook" warning advice contradicts the companion guide.** This guide leads with "Press Use it anyway to go on to the preview ... or Do not use it to stop" and only then names the clean fix; page 37 repeats "or press Use it anyway" as an equal choice. The companion guide (pages 12 and 18, Fable-reviewed and applied) leads with the clean fix and allows Use it anyway only "if you cannot rerun, and the only change was your own edit". Someone holding both guides gets opposite instincts. Change page 27 step 4 to: "If a yellow warning appears, the workbook changed after the 'for Update' file was made, so stories in the update may already be in the workbook, or others may be missing. The clean fix: press **Do not use it**, make a new 'for Update' file and run the station again. Only if you cannot rerun, and the only change was your own edit, press **Use it anyway**: the save still checks everything and only fills blanks, but read the preview carefully for stories the workbook already has." Change the page 37 row to the same order.

3. **Page 32: the refresh-file screenshot and caption show the old program message.** The gray line in the picture says "(shared drive, email or Teams)" and the caption says "The program's own message also mentions email and Teams". In 4.3 the message is "Pass it to the others on the shared drive, OneDrive or a USB stick (it can be too big for email or Teams)", which is exactly what the companion guide's page 16 caption describes. The two guides now disagree about what the program says. Change: retake the picture from 4.3, or crop it above the gray line; drop the parenthetical from the caption.

4. **Pages 33, 34, 37 and 38: a new colleague's first copy is never explained.** The program zip has no workbook or library. A fresh copy says "No workbook yet", and page 37 answers "A reader brings in the refresh file the keeper gave them", but the keeper's normal **Make refresh file** makes a short one once any refresh file has been made before, and a short one cannot fill an empty copy. The keeper must use Repairs, **Make a FULL refresh file**, once per new person (page 34 has the button, but nothing points a new person or the keeper there). Change: add a short block "A new colleague's first copy" after the reader panel on page 33: 1. Unzip the program zip on their PC (it starts as a reader copy, with no workbook). 2. Start it: the page says "No workbook yet" and Tracker files opens by itself. 3. Keeper: Tracker files, Repairs, Make a FULL refresh file; pass it on by the shared drive, OneDrive or a USB stick (hundreds of MB). 4. The new person drops it on Bring in refresh file. Change the page 37 "No workbook yet" row to "...the keeper makes a FULL refresh file for them (Repairs, page 34)". Add a "Reader: first time" line to the cheat sheet.

5. **Pages 26 and 38: office PCs cannot open the Update station, and this guide does not say so.** The office network blocks the address claude.ai pages run from (*.claudeusercontent.com; IT has been asked to allow it). The companion guide makes this its first "Before you start" point and has a callout for it; this guide's page 26 step 3 ("Load it into the Update station") and the cheat sheet ("Update station, load it, Update database, download the folder") read as if the station opens on the office PC. The first person who tries will think the station is broken. Change: add to page 26 step 3: "Office PCs can't open the station yet (the office network blocks it; IT has been asked to allow it). Copy the file to another computer, run the station there, and bring the update zip back. The companion guide, page 2, has the steps." Cheat sheet, Keeper step 2: add "(on a computer that can open it; office PCs can't yet)".

6. **Page 3 and page 35: the Mac copy is missing.** A Mac version of the program exists (`Start Tracker.command`, `Install update.command`, a Terminal window in place of the black window, the default browser in place of Edge, and a first-start step: unzip in Terminal, or right-click, Open, or System Settings, Privacy & Security, Open Anyway). The guide is written for "your PC" only, and the program's own messages already say "Terminal or command window". If anyone will run the Mac copy, add a navy callout "On a Mac" on page 3 (start file, Terminal window, the Open Anyway step, same files and buttons) and one line on page 35 ("On a Mac, run Install update.command the same way; press Return"). If no Mac copy will be in use, say so in one line on page 1 ("This guide covers the Windows copy").

7. **Page 4: the text and the pictures disagree.** Callout 4 says "The number on it (21 in the picture)"; both pictures show 29. The close-up caption says "2 Spreadsheet, 3 Tracker files, 4 Manage", but the crop shows only Tracker files and Manage (Spreadsheet is cut off at the left edge), and the crop's bottom edge shows a stray orange arc, the top of the tab-bar outline. Change: "(29 in the picture)"; widen the close-up to include Spreadsheet or change the caption to "3 Tracker files, 4 Manage"; crop above the tab bar.

8. **Pages 8 and 10: wrong page references.** Page 8 "see Story travel, page 16" should be page 21 (16 is the Reporters page). Page 10, callout 6, "To change a rating for everyone, see page 12" should point to page 13, where "What happens to your edits" gives the Excel route. Also page 25 "Repairs (closed at the bottom)" and page 13 "(page 34)" are right; keep.

9. **Page 8: the "Two stories ticked" bar still has a smudge above it.** At 200 dpi a strip of blurred page text shows along the top edge of the crop (the round-1 fix did not take). Crop to the bar's own edges.

10. **Pages 7, 12, 17, 18, 20, 21, 23, 25, 26, 28 and 31 are more than half blank; pages 14, 19, 33, 34, 36 and 38 are a third blank.** The style guide's pages are full to the footer. Causes: a forced page break before every list-tab sub-heading (Outlets, Press releases, Bills and Story travel each sit alone on a page with a half-page gap under them), the Edit form split across pages 12 and 13 with half of page 12 empty, "The four parts" pushed to page 25 (two-thirds blank) by the tall panel picture on page 24, and one 4.4-inch-wide panel crop per page from 26 to 31. Change: remove the forced breaks before sub-headings in "Tabs 4 to 8" and Manage; print the keeper panel on page 24 at about 3.6 in so "The four parts" and the Close Excel callout fit under it; put the two Edit form crops on one page; let the for-Update section follow on page 25's space; place the page 28 preview crop and the page 29 "Items that need a person" crop side by side (both are narrow). Target: 30 to 32 pages, no page less than two-thirds used except the last page of a section.

11. **Pages 16, 18 to 21: table text at the limit of print legibility.** The Reporters table (page 16) prints its body at about 6.4 pt and its sublines at about 5.4 pt, because the 1800-px shot is printed 6.1 in wide while the Outlets, Press releases, Bills and Story travel shots (same capture width) are printed 7.2 in and come out at about 7.5 pt body. On those four, the gray sublines ("Virginia · Statewide California · Online news", "Akron Beacon Journal · by ...") and the chart axis labels print at 5.8 to 6.4 pt; the captions carry the meaning, so they pass. Change: print page 16 at the same 7.2 in as the others, or crop it to the first five columns. Page 34's Repairs screenshot prints at 6.2 to 7.3 pt; it is fine because the table beside it carries every word, but say "(the table lists the buttons)" in its caption. Page 11's full-page view prints at about 3.3 pt; acceptable as an orientation thumbnail, but add "(shown small; nothing in it needs reading)" to the caption so it does not look like a mistake.

12. **Page 34: say which Repairs a reader has.** In 4.3 a reader copy's Repairs holds only Rebuild the page; Accept the workbook, Make a FULL refresh file and Rebuild saved copies are keeper-only (panel.js, and the server refuses them). Add "(keeper only)" to those three rows, or one line under the table: "On a reader copy, Repairs holds only Rebuild the page."

13. **Page 36: "backups: The newest few are kept" sits next to "Nothing is deleted".** The saver keeps the newest three and moves older ones to `backups\_to_delete`. Say so: "The newest three are kept; older ones are moved to _to_delete inside backups." Then the callout and the row agree.

14. **Page 1: "It runs inside a Microsoft Edge window".** The launcher opens Edge's app mode when Edge is there and otherwise the usual browser (and prints "The page opened in your usual browser"). Add "(or your usual browser if Edge is not on the PC)". Same on page 3 step 3.

15. **Page 37: two rows worth adding, from the program's own messages.** "Another save is running (... minutes so far)" (amber box in the panel): wait for it; if it never ends, the tracker stops it itself and says so. And the companion guide's row "The PC says the update was already saved": you brought in a zip that was saved before; nothing is added twice; use the newest zip. Both are likely first-month questions.

16. **Page 27: the warning picture's fingerprint differs from the panel pictures.** It says "workbook now: bc21c9fb"; pages 24, 26 and 33 show 41315fe0. Page 1's note covers it, but one phrase in the caption avoids the puzzle: "(taken before the save on page 30, so its fingerprint is the older one)".

17. **Page 22: a program wording to pass on, not a guide change.** Manage's "Add saved pages" text ends "but their tone and author are saved for everyone". On the PC a reader's additions never leave that copy, and the keeper's reach the workbook only through a save. The guide's row wisely says "show only on this computer"; the program's own sentence should be brought in line (builder's note).

18. **Hidden anchor text.** Twenty pages carry a 1-pt word at the top left ("QQWORDSQQ", "QQSTARTQQ", ...), real text used to compute the contents page numbers. Invisible in print, but it shows when someone searches, selects all, or uses a screen reader. Strip it before export (or anchor on element ids instead of text).

19. **Small continuity items.** Page 6 continues Home with no "HOME, CONTINUED" kicker, unlike every other continuation. Page 7 opens with the orphan line "new view button. Saved views stay in your copy only..." above two screenshots; keep the paragraph together. Page 9's close-up cuts words at its right edge ("library c", "Newspa"); the caption says "(left side)", so crop a little tighter or end the crop at a word. Page 10's panel crop starts with the bottoms of the badges sliced off; start it at the tone box.

## What is right (no change)

- Every quoted program message checked matches 4.3: the start and stop lines, "already running ... from a different folder", "Port 8765 ... used by another program", "Is the tracker's ... window still open?", "That is not a .zip file", "The workbook is not the one the tracker last saved", the Accept "Are you sure?" warning, the for-Update and refresh-file result lines (except item 3), the preview and save lines, the installer's steps and `_previous_version`.
- "Edits fill empty fields only", also for Tone, is right (the save marks an edit that disagrees with a filled cell as reported and leaves the cell). The tone Change menu writes only to this copy's own data; nothing in the save reads it. Notes and saved views stay out of refresh files and the workbook.
- The Repairs buttons, the reader panel, the data folder table, the Removed tab, `db\_applied\edits`, "newest three backups" (with item 13), the "for Update" file name and the refresh-file sizes all match the program.
- Style: fonts, the navy cover block, letter-spaced kickers, the rule under each heading, amber-edged callouts, navy tables, framed screenshots with gray captions, the footer and the two-box cheat sheet all match the NewsBank Download Guide. Contents has page numbers. Words are defined before use. Claude and TinyFish are defined.
- Consistency with the companion guide, apart from items 1 to 5: the for-Update steps, the preview description, the "Items that need a person" table, Save / Do not use this update, "Keep the black command window open", the refresh-file advice (shared drive, OneDrive or USB stick) and the companion's title all agree.

## Risky to tell a user (summary)

- Item 2: pressing Use it anyway as the first choice on an older-workbook warning.
- Item 4: giving a new colleague a normal (short) refresh file; their copy stays at "No workbook yet".
- Item 5: trying to open the Update station on an office PC and concluding it is broken.
- Items 1 and 3: quoting program messages that 4.3 no longer shows.
