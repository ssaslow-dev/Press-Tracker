## 1. How today's pipeline handles a NewsBank story

**There is no Update path for a NewsBank find. It is hand work, then a chat.**

- The Update button only *reminds*: `code/tracker/41_update_search.js:216-231` (`nbStatus`, `nbBanner`): "download everything from <date> on as batch PDFs into Documents/Gabriel press PDFs, then ask Claude to extract them", and a button that logs `{mode:'newsbank', newsbank: TODAY}` (`42_update_buttons.js:163`; `43_update_log.js:53` keeps `mode: newsbank`). That run doc has no rows. `lastSearched()` (41:616) looks only at `mode === 'find'`, so it never moves `searched_to`.
- Extraction was a one-off script: `code/extract_nb.py` (split by the "Citation (apa Style)" line: `split_items` 36-52; header parse `parse` 69-120; docref repair 30-34; matched to a Companion workbook `All PDF Items`). Per-story PDFs came from the "NewsBank split" agent (BOARD T25: 5,574 files in `work/nb_split`, add-only into the library; DECISIONS 92: citation-page-only splits are not saved copies). Print clipping is paused (HANDOFF 3.13).
- Nothing in `sheet_task.py` reads a NewsBank source. Its page saver `apply_pages` (`code/sheet_task.py:1422-1508`) only writes HTML: `ws<Article ID><o|r>-<Story ID>.html` (1486-1495), `File type` "HTML" (1507). A pages doc whose text is NewsBank's is refused by the web copy checks (copy check R1: "page host infoweb.newsbank.com is not the Publisher link host", seen in the build's first run).

**What a NewsBank row looks like today** (the snapshot workbook, 3,874 rows with `Data Source` = `Newsbank`, the sheet's own spelling; 2,290 Reprints, 1,584 Originals):

| Column | Value |
|---|---|
| Data Source | `Newsbank` |
| Date source | `NewsBank` (2,648) or `print edition` (1,206) |
| NewsBank article link | `https://infoweb.newsbank.com/apps/news/document-view?p=WORLDNEWS&docref=news/1AB748C7AEBF1E08` (no trailing dot, canonical host; the tracker rewrites to the State Library host for display, DECISIONS 60-61) |
| Newsbank APA citation (article) | the full citation line, trailing dot kept |
| Publisher link, Link status | filled on 1,216 rows (`Publisher URL` 1,192, `Syndicated copy` 13, `Search link only` 10); blank otherwise |
| Edition / Format / Page / Section | `Print` (1,207) / `Web` / `Web + Print` / blank; Format `Article` or `Print`; Page and Section from the header |
| Word count | NewsBank's `N Words` (3,753 filled) |
| Saved Copy? / File type / File name | `Yes` / `Newsbank pdf` / `nb<Article ID><o\|r>-s<Story ID>.pdf` (HANDOFF 9; 3,751 rows) |
| Print columns | `NewsBank print article link`, `Print Article ID`, `Print date` ... only on Web + Print rows (CONTRACT line 75); print-page pointers live in "Unlinked print pages" |

**Docref patterns** (400 sampled single-story PDFs): `news/<16 hex>` (396 of 400) and `image/v2%3A<hex>%40AWNB-<hex>%40<julian 7 digits>-<16 hex>%40<page>-<hex>%40` (print-page images). `pdftotext` drops the hyphen after the julian date (HANDOFF 3.14; `extract_nb.py:33`). The citation in a downloaded PDF carries the library proxy host (`infoweb-newsbank-com.castatelib.idm.oclc.org`, seen in the 2026 print clips) when the reader signed in through the State Library, so the station compares **docrefs**, not hosts.

**How the page dedupes:** `covLoad` (`40_update_outlets.js:105-133`) indexes every link of every Coverage row with the query kept for NewsBank (`covNormU` 100), so `covLink` finds a NewsBank record by docref; `covHit` (134-151) adds headline + outlet + date; `dupOf` (297-324) is the Jaccard test; reprint candidates come from `covHit`/`dupOf` (41:725-745, 841-870). The page never decides a reprint by text (41 header comment); `sheet_task` does, with `reprint_rule.py` (REPRINT90-v1).

**How a saved PDF's text is read.** `release_rule.file_versions` (`code/release_rule.py:150-168`): a library `.pdf` is read with `pdftotext`, cut at "Citation (apa Style)", and used as NewsBank text; `sheet_task.row_versions` (`sheet_task.py:2665-2680`) feeds it. On the PC, winpack patch 01 swaps `pdftotext` for `pdftext_pypdf.pdf_text` (`work/localapp/winpack/patches/01_release_rule_pdftext.patch`, `pdftext_pypdf.py`). `build_data.py` reads no PDF. The viewer's text for a NewsBank row is the shard HTML `make_copies.nb_page` (`code/make_copies.py:84-97`, `<article class="jg-pdf-text">`) from `work/texts/nb/*.json` (extract_nb output); the tracker's PDF.js code (`06_story_sheet.js:110-142`) is for PDFs dropped on the Manage panel. The Clips search reads the same shard text.

**How a PDF ends up as `<year>/nb<NNNNN><o|r>-s<NNNNN>.pdf` today:** split by the agent, named from the row's Article ID and Story ID, copied add-only (`saver.commit_library` copies every file under the pages folder, `work/saver/src/saver.py:920-935`).

## 2. Design

### 2.1 Libraries in the page (pinned, no outside code)

`vendor/PINS.json`: **pdfjs-dist 4.10.38** (Apache-2.0; text and positions) and **pdf-lib 1.17.1** (MIT; copies page ranges). `vendor/fetch_pdflibs.py` downloads from `registry.npmjs.org`, checks the tarball's **sha512 integrity** (the npm value) and each kept file's sha256; `build_station.py` re-checks on every build and inlines them as `<script type="text/plain">` blocks (about 2.3 MB, page now about 3.3 MB). pdf.js ships as ES modules: the build removes the module syntax mechanically (`import.meta.url`, which sits in a Node-only branch, becomes a constant; the closing `export{...}` becomes `globalThis.pdfjsLib = {...}`) and asserts the result. 4.10.38 is past the font-eval flaw fixed in 4.2.67 (CVE-2024-4367); the page still passes `isEvalSupported:false`.

**No worker needed.** pdf.js is run with its "fake worker": the worker's own code is evaluated first in the page (`globalThis.pdfjsWorker`), which pdf.js finds before it would load `workerSrc`. Tested under a deliberately strict policy (inline scripts only; no eval, no worker, no blob: script, no connections): no worker started, no violation, no outside request (`tests/newsbank_test.js`). The real artifact policy was not visible from here; if it forbids something the test policy allows, the first real drop will say so (nothing else in the station depends on it).

### 2.2 Finding stories (`src/nbparse.js`, pure functions, node-tested)

1. pdf.js `getTextContent` gives items with positions; items within 40% of a font height share a line (`linesFromItems`). A repeated short line in a page's top or bottom margin on at least half the pages (running head, page counter) is dropped from the text (not from the PDF).
2. A story **ends** with its citation: the line "Citation (apa Style)" (also `CITATION (APA STYLE)` of the print-page layout), then lines until the joined text holds `docref=` and ends with a full stop (the rule of `extract_nb.split_items`); a copyright line right after the citation (print-page layout) is kept with it. The next story starts on the next line. So a story needs no page break.
3. **Where to cut when a story starts mid-page.** Chosen: **exact page ranges, plus a crop and a recorded band.** The PDF of a story holds every page from the one its header starts on to the one its citation ends on (no overlap, no re-rendering: nothing is redrawn, so fonts, photos and non-Latin text are byte-identical to NewsBank's). On a page shared with a neighbour, the copied page gets a `CropBox` to the story's band (halfway between the neighbour's last line and this story's first), so it *looks* cut; but a text extractor ignores a crop box, and the PC's text readers (reprint rule, release rule, Clips) would then see the neighbour's lines and could call two unrelated stories the same text. So the band is also written into the PDF's info dictionary (`/AJGBands`, JSON) and into the pages doc (`nb.batch.bands`), and a band-aware reader (`newsbank_pc/pdftext_pypdf.py`) keeps only text inside it (tested: the neighbour's headline is in the plain reading and absent in the banded one). Rejected: *re-rendering* (cannot reproduce NewsBank's fonts/photos without the source; text-only reflow would lose the PDF's point), *overlap ranges* (the neighbour's text, unbounded), *rewriting content streams* to delete the other lines (fragile, cannot be checked without real files). **Evidence that it rarely matters:** in the 3,993 single-story files, 299 of 300 sampled hold exactly one citation and the six measured all begin at the same top margin and end mid-page, which is how a "new page per story" batch splits cleanly; the continuous layout is handled anyway. The station notices and says "some stories start mid-page" per batch.
4. Parse (`parseStory`): header (`Month D, YYYY | source`, Spanish `D de mes de YYYY | ...`, the "kicker | headline" form of `extract_nb` route G), `Author:`, `Section:`, `N Words`, `Page:`, `OpenURL Link`; the body; the citation (`(YYYY, Month D)`, author initial form, title+outlet run together as `Headline.Outlet`, URL wrapped over lines and broken after `document-view?`; whitespace removed from the URL, hyphen after the julian date restored). Header first, citation as a cross-check and as the only source when a header is missing (flagged "check", with the split of `Headline.Outlet` a guess). A story with fewer than 15 words of text is **thin** (citation page only): row proposed, **no PDF, Saved Copy? No** (DECISIONS 92). `/image/` docrefs are **print pages**: not rows, listed in the run's `print_pages` (the existing "N print pages to clip" bucket). Each batch is checked: not 20 stories (training deck: only the last may hold fewer), unreadable headers, text after the last citation.

### 2.3 Dedupe

Per story, in this order (`nbScreen` in `src/newsbank.js`, run inside the tracker's own scope so it uses the tracker's own functions): (1) NewsBank id: the docref against every link of every Coverage row, every story and reprint link (so a story only in "NewsBank print article link" also counts); (2) the same id earlier in the PDFs dropped this session; (3) `covHit` (same outlet and headline within 3 days: already in the tracker; another outlet with the same headline: a **reprint candidate** of that story) and `dupOf` against the stories added this session; (4) later, among the new stories themselves, the Update's own rule (keep the earliest, the other becomes its reprint). **Identical batch dropped twice** (same sha256): the second is skipped by name. A batch dropped again with different bytes (a re-download) is caught by (1)-(2). Nothing is added twice within a session; across sessions an unsaved update is re-found, which is intended (FORMAT.md "Fingerprint") and the save drops duplicates.

### 2.4 What happens to each new story (the Update button's own steps)

- **Classify, tone, topic, role, language, English headline and summary:** the tracker's own `classifyPrompt` through `sample`, 20 per call, with a short NewsBank preface (copy NewsBank's date, outlet and headline; a story whose text lacks his name stays, because NewsBank drops captions and guest lists: HANDOFF 3, DECISIONS 81; drop only another Jesse Gabriel or non-press). `toRow` builds the story record exactly as for a web find. Headlines Claude did not translate go through the tracker's own `translateHeadlines`.
- **Reprints are never judged by text here.** A reprint candidate gets a Reprint row, its own `rp-` pages doc and a `reprints` doc, exactly as for a web find; `sheet_task`'s string-of-text rule decides at save time (verified end to end: a synthetic reprint whose text is not the story's "was added as a story of its own").
- **Authors:** NewsBank's `Author:` goes into `Author / byline`; the PC's `auto_fill_row` splits it (Author 1..N). A byline Claude found is written as an `authors` doc as in the Update.
- **Original publisher link:** a TinyFish `search` for the quoted headline (one call per story, 30 a minute), keep results not on NewsBank, library proxies, Google, aggregators or skipped hosts whose title holds at least 80% of the headline's words and whose date is within 4 days; if the outlet is known (its hosts in the tracker's own rows) require its host, else accept a host that names the outlet; then one `fetch_content` per batch of up to 10 candidates and **confirm**: at least two shared 6-word runs with the NewsBank text, or (host evidence and his name on the page). A blocked or paywalled page with a strong host match is kept as `Search link only` (text could not be compared). Nothing found: both Publisher link and Link status stay blank and the Team note says why. TV, radio and podcast records are not searched. Optional (a checkbox; default on). Then the Update's own `originCredit` (wire / credit-line originators) runs on the new stories.
- **Rows** are built by the tracker's own `proposeRows` (covcols order, `NEW-<run>-n` / `sNEW-<run>-n` placeholders, `Tracker story code`, `_page`, `_origin`), then NewsBank's conventions are set (`nbRowFill`): Data Source `Newsbank`, Date source `NewsBank` / `print edition`, canonical article link, citation, Section, Page, Word count, Edition, Format, Team note ("NewsBank PDF <file> #<n>"); `File name`, `File type`, `Saved Copy?` are left for the PC. Shapes: `updatefolder/FORMAT.md` section 2b.

### 2.5 In the zip and on the PC

- `files/<id>.pdf` entries (id = `nb-` + 16 hex of the docref's hash), each with sha256 in the manifest, 32 MB cap each, zip cap 256 MB (the station stops adding at 180 MB of PDFs), allow-list and "a pages doc names every PDF and gives its sha256" cross-checks. `formats.pdf_problems` refuses a PDF with `/JS /JavaScript /Launch /EmbeddedFile(s) /OpenAction /AA /RichMedia /XFA /SubmitForm /ImportData /GoToR /GoToE /Encrypt /Rendition /Movie /Sound` by two looks (text outside stream data with `#xx` names un-escaped plus decoded object streams; and every object through pypdf when present). Tested with OpenAction JS, document JS, a launch action, an embedded file, JS in an annotation, `#xx`-obfuscated names, an encrypted file, junk named `.pdf`, an unreferenced PDF, a missing PDF, wrong checksums. The station's own PDFs have annotations, actions and page metadata stripped.
- The PC save needs three small patches (`work/localapp/newsbank_pc/`): `sheet_task.py` (save the PDF, not HTML), `date_rules.py` (Date source), `pdftext_pypdf.py` (band-aware text). Proven on a copy of the snapshot workbook with the station's real zip: 33 rows added, 33 PDFs named `nb<ID><o|r>-s<ID>.pdf`, Saved Copy Yes, File type `Newsbank pdf`, verify ok, no conflicts. How to wire them into `assemble_app.py`: `newsbank_pc/README.md`.

### 2.6 Sharing with the interns

- **Whose connectors:** a shared viewer's capabilities run **as the viewer**. `mcp` "uses the viewer's credentials" (each intern's own TinyFish connection, consent asked on first use), `sample` is the viewer's own Claude (consent on first call, their usage), `downloads` asks them to confirm each save. Nothing runs on Sammy's account. A viewer without TinyFish connected gets `server_not_connected`; the card then still reads, checks, rates and packs, only the publisher-link lookup is off (the page says so). Without `sample`, rows are marked and need checking.
- **Who can open it.** The artifact declares `mcp`, and the capabilities text says an artifact that declares it cannot be shared "anyone with the link" and "outside viewers get `null`" for `mcp`; `db` needs a signed-in person. So: **share with specific people (inside Sammy's organization)**, as NEWSBANKPDF-v1 says. Whether an invited guest outside the organization gets TinyFish/Claude is not something this session can test; Sammy should try with one intern before telling them all.
- **What Sammy does:** (1) republish the station (private) and share it with the interns by name; (2) each intern connects **TinyFish** in claude.ai Settings, Connectors, and allows it, Claude and downloads on first use; (3) the intern needs the keeper's current **for-Update file** (the dedupe depends on it) and sends back the update zip(s); (4) the keeper takes them in with "Bring in update" on the PC (one run per save: the saver saves the newest undone run, so several NewsBank zips are taken in one after another). Interns' PDFs never leave their browser tab; the artifact db is never given NewsBank text (documents holding it are not mirrored for recovery, so a closed tab loses the NewsBank part and the card says to download first).
- Copyright and terms: the update zip holds NewsBank article text and PDFs. It is a private file moved by hand, like the batch PDFs today; it must not be put behind a public link (HANDOFF 2, "no Exa / never full text behind a public link").

## 3. Costs and limits worth knowing

- TinyFish: about 2 calls per new story with links on (search + page opens): 20 stories about 90 seconds at the code's own 2.1 s gap; the Update's 700-search plan is not run. Claude: one call per 20 stories (plus headlines to translate).
- A whole backlog (6,500 stories, 329 batches) is an afternoon per few dozen batches, not one session; the PDF cap (180 MB per update) stops a session earlier.
- pdf.js runs on the page's main thread: a 20-story batch took well under a minute in the test; large photo-heavy batches will be slower but the page stays responsive between pages.

## 4. Where the build differs from the plan above, and what is unproven

- Nothing unproven in the code paths, but **all tests use synthetic PDFs** that copy the single-story layout (A4, headline, date line, `Author: .. Section: .. N Words`, `Page:`, `OpenURL Link`, copyright, citation wrapped at `document-view?`). A real batch may differ in: furniture lines (running heads), whether stories start on new pages, the citation's exact wrapping, the date line for non-English sources, how a print-edition item and a TV transcript look, non-Latin extraction order. **What the real batch must show:** `pdftotext -layout` of the first two stories, one print-edition item, one TV/radio item, one non-English item, the PDF's page count, and whether the stories start on new pages.
- The artifact's real Content-Security-Policy and the real `downloads` size limit for a zip with 20-200 PDFs (up to tens of MB) are unproven.
- The "own page" confirmation is conservative (it prefers a blank link to a wrong one); the real hit rate is unknown.
- Broadcast items: a source like `Morning Edition [NPR]` becomes Outlet NPR through the tracker's own `covOutletName` and a Team note asks for the show to be checked (SHOWNET-v1 is applied at extraction in `extract_nb.py`, not in `sheet_task`).
