## Date-sensitive tab tests (item 4)

| Path | What | Why |
|---|---|---|
| `build/tests/tabs/harness.js` | Every page runs with a fixed clock (`browserContext.clock.setFixedTime`): default 2026-10-30 20:00 UTC (13:00 in Los Angeles), the day of the data snapshot. `TABS_NOW=real` uses the real clock, `TABS_NOW=<ISO instant>` another. New `h.skip(name, why)` and `h.v18Full`; the summary line counts skipped checks. | The tabs count "last 3 / 12 months" from the page's own today (`code/tracker/00_head.js` TODAY, Los Angeles date) while the tests counted from the browser's local date: the counts moved with the calendar and differed by a day between UTC and Los Angeles. |
| `build/tests/tabs/_framework.test.js` | The two checks that compare Home and Clips with the v18 baseline page (`build/shell/index.html`) report SKIP when that file is absent. | The repository has only the stripped `build/shell/shell.html`, so the comparison cannot be made. |
| `.gitignore` | `build/tests/tabs/srv/{index,stub,v18}.html`, `srv/blocks/data.json`, `work/tests_out/` | Generated by `build_testpage.sh` and the harness. |

How the suite is run in this repository (no `build/shell/index.html`, no `work/coverage_current.xlsx`): `bash build/build.sh` first (writes `work/build_last/`), then
`BASE=$PWD/build/shell/shell.html BLOCKS=$PWD/work/build_last/lib/blocks XLSX="$PWD/data/AJG Coverage - NewsBank.xlsx" bash build/tests/tabs/build_testpage.sh`, then
`cd build/tests/tabs && NODE_PATH=<global node_modules> XLSX=<same workbook> MOD=all node harness.js`. These regenerate the tracked fixture blocks in `build/tests/tabs/blocks/` and `srv/blocks/`; `git checkout` them afterwards if only the test result matters.
