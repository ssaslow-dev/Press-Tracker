# release_pickup — Insights > Press releases (agent-ins-release_pickup, 2026-10-27)
- Shows: Gabriel's own/office/caucus press releases, newest first, filter by year and issue (params `year`, `topic`; `id=<Story ID>` opens one release). Tiles (follow the filters): releases, average distinct outlets per release, % of releases followed by original reporting within 7 days, % of runs on the release day (+ median lag of later runs). Each release expands to: outlets that ran it (date, lag in days from the release date) and the tracker stories that followed within 7 days (click = story panel); "All <bill> coverage in Clips" link.
- Data: new block `ins-release_pickup` from `release_pickup_data.py` (Coverage rows with Press release = Yes; ~17 KB, 72 releases / 100 runs). Follow-ups computed in the browser from `ctx.D` (stays current after Update/Refresh).
- Criteria (IN): issuer = Gabriel's Assembly office (his release via the Assembly Democratic Caucus / asmdc, or an outlet posting it verbatim, with him as lead; joint releases where he is a named lead count), his office as Budget Committee chair, or the Legislative Jewish Caucus from Nov 2020 (chair; co-chair 2023-25). OUT: Governor, AG, other members, caucus-wide releases that only list his bill; advocacy groups (EWG, Consumer Reports, Everytown, JPAC/Jewish California, CAA, SWC, CAPA…), companies/PR wires. Decided by reading each release's text; the curated table in the .py is authoritative for all Press-release stories that existed on Oct 27 (max s04674). Later stories: auto-included only if the headline names him (Assemblymember/Asm./Budget Chair Gabriel) or the Legislative Jewish Caucus (tagged "added automatically").
- Assumptions: copies of one release filed as separate stories are merged (e.g. PublicNow + US Fed News + local reposts). Release date = earliest dated run. Original reporting = tracker stories (day-dated) dated release day..+7 with a shared bill; if the release has no bill, the same issue (not "Other / roundup"/"Unassigned"; 2 releases unchecked). Bills/issue per release are curated (sheet Bills column is a fallback). A match = coverage followed, not caused.
- Borderline calls: s04431 (Gabriel + AG Bonta, joint) IN; s03298 (AB 1185 signing, JPAC-voiced) OUT; s00308 (UC "What they're saying") OUT; s01477 (2020 COVID newsletter from his office) IN; PublicNow s01893/s02112 (no text, unknown issuer) OUT.
