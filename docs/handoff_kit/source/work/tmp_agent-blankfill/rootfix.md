# Root cause: blank Medium and raw-domain Outlet on new rows (agent-blankfill, 2026-10-28) — proposal for the v20 code pass, not applied

## Why it happened
1. **Agent writers copy outlet fields by exact name only.** work/tmp_agent-newoutlets/build.py (OUTF, `outlet_val`) and work/tmp_agent-reviewweb/build_rw.py (same block) fill Publisher, city, county, state, Medium and Reach from the most common value among rows with the *identical* Outlet string. A brand-new outlet has no rows, so all six stay blank. There's no fallback by page type, and `norm_outlet` isn't used, so variants such as "bostonglobe.com" vs "Boston Globe" miss as well.
2. **The outlet name falls back to the bare host.** newoutlets process.py:132 sets `'outlet': dom2out.get(domain) or domain`, and tracker 40_update_outlets.js `outletFor(host)` returns `host` when the log has no name for the site. Result: csun.edu, kesq.com, stocktonia.org and the rest. The domain map also produced one wrong name ("Produce Marketing Guide" for producemarketguide.com) and mapped thepress.net to "Brentwood News", which picked up the Los Angeles county of an unrelated row.
3. **The tracker leaves Medium blank on reprints.** 40_update_outlets.js `repRow` never sets 'Medium'. Originals get `r.media || ''`.
4. **The sheet task never checks.** sheet_task.py `add_row`/`auto_fill_row` writes whatever the run doc proposes. It fills Reach by consensus but has no rule for Medium or Outlet. `verify()` only compares old rows and the Originals mirror, so a new Original with a blank Medium or a domain Outlet passes.

## Fix (proposed)
A. **sheet_task `auto_fill_row`**, for every new row: if Medium is blank, use the unanimous Medium of the outlet's rows (`norm_outlet(name, city)` key, the same as `reach_for`). Otherwise infer it from the page type using only the sheet's values: TV station site → TV; public radio → Radio; university newsroom / online-only site / Patch → Online news; blog platform (dailykos, substack, medium) → Newsletter or blog; student paper → Student newspaper; podcast host (podcasts.apple.com, spotify, podbean) → Podcast; print paper's site → Newspaper. If it's still unknown, the row goes to the run result `outlet_unresolved[]` and is held, not written blank. Fill Publisher / Outlet city / county / state the same way (unanimous outlet values only).
B. **Outlet name:** if Outlet matches a bare host (`^[\w.-]+\.(com|org|edu|net|info|news|co)$`) or a URL, look the name up in the sheet by the host of the rows' Publisher links (most common Outlet for that host). If the lookup fails, use og:site_name or the masthead from the saved page, in NewsBank style (`covOutletName`). If neither works, put the row in `outlet_unresolved[]`. Apply the same rule in tracker `outletFor` (prefer og:site_name over the host) and `repRow` (add `'Medium'` from `covMedium(outlet)`, the counterpart of `covReach`).
C. **verify():** fail (`ok: false`) when any row added in this run has `Original or reprint` = Original and a blank Medium or Outlet, or an Outlet that matches the bare-host pattern. Give a warning for the same on new Reprints. Add a fixture in build/tests/sheet_task/ (new Original from an unknown host, which must be resolved or held).
D. **Agent writers** (any future one-off build.py): call `sheet_task.Task.auto_fill_row` instead of their own `outlet_val`, so A/B apply everywhere.
