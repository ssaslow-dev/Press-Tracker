# Bills tab (bills.js, agent-tab-bills, TABS-v1)
- List: one row per author-led bill AND session (LegInfo role "author…" = author or co-lead; coauthored bills and Committee on Budget trailer bills excluded). 273 items; default filter "Has coverage: Yes" (63 at v18 data). AB 787 = two rows (2021–22: 3 stories, 2023–24: 9).
- Search: bill number (AB 418 / AB418 / 418), title, session. Facets: session, final status (Signed into law / Vetoed / Adopted / Pending / Died; held/inactive/"last in" count as Pending only in the current session), issue (topics of its stories + releases), milestone reached, activity date range (milestone or story dates), has coverage, has press release. Columns: bill, title, session, final status, stories, last activity. Export: Copy bill list, Copy list (TSV), CSV (+ role, introduced, first story, releases, issues, LegInfo history URL).
- Bill page #bills/<slug>: facts (session, role, final status, introduced, last action, stories, latest story, busiest week, press releases, "LegInfo history" link with copy icon left), milestone timeline (stories per Monday week, dashed rules = introduced/floor/final action, dots = committee votes; axis = niceMax of busiest week; click a week -> page list filtered to that week via `when`), milestone table, related releases (official link + copy icon, date, issuer, pickups), then the framework's coverage chart (AXIS-v1) and story list. No Clips jumps.
- Data: ctx.bills() (billsinfo), ctx.block('bill_timeline') (Bills tab snapshot: milestones + final status), ctx.block('release_pickup') (bills mentioned per release), ctx.D. No _data.py.
- Session rule (Data's and the old view's): a story/release goes to the latest session of that bill number that started (Dec 1 of the prior year) on or before its date.
- Slug (BILL-SLUG-v1): ctx.slug(bill + ' ' + session label), e.g. ab-418-2023-24, ab-787-2021-22, abx1-4-2025-26-1st-ex-sess. Module property `billSlug(bill, {date}, ctx)` (on the registered module, TB.mods.get('bills').billSlug) returns it, '' for coauthored/unknown bills. find() also accepts a bare 'ab-418' (most covered session).
- Legacy: bill + s -> that page; bill alone -> most covered session; unknown bill -> list searched for it (cov=~); range dropped.
- Test: MOD=bills 140/140 (1400 + 390). Screenshots: work/tmp_agent-tab-bills/shots/{list,page,page_timeline}_{light,dark}_{1400,390}.png.
- Gaps: 4 extraordinary-session bills tagged on 6 stories (SBX1-1/2/3, ABX1-4) are dropped by the tracker's bill parser (splitBills regex), so they show 0 stories; 6 coauthored bill-sessions with coverage are not listed (by rule).
