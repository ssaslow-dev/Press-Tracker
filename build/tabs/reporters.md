# Reporters tab (build/tabs/reporters.js, agent-tab-reporters, TABS-v1)
- What it shows: one row per byline entry (tracker authorKey + canon) over stories that pass the story filters. Gabriel's own op-eds, "Jesse Gabriel", and author strings that are the story's author-title are left out. Row columns: name (type line for non-people), outlets (canonical via ctx.outlet, most stories first, top 2 + "+N more"), stories, last story (opens the story panel), top 3 issues, tone avg (ctx.tone, e.g. "−0.1 (n=14)", rated stories only, "—" if none), and negative count (Negative + Very negative).
- Story facets (unit level, applied before grouping): date range (default last 24 months), issue, bill, outlet, Reach, Medium, language.
- Reporter facets (item level): byline type (default People; others are Staff bylines, Editorial boards, Wires, Organizations), story count, tone (any negative / none / average below or above neutral / no rated story), and active within (latest story).
- Search covers name and outlets. Export offers Copy names ("Name (Outlet)", top outlet), Copy list (TSV) and CSV (adds byline type, sheet title, bills, last headline). Rows show 100 at a time on desktop and 25 on a phone, with Show more. The one-sentence answer names the top 3.
- Reporter page #reporters/<slug> (unique slug over all entries; it ignores the list's filters). Header: outlets (counts, links to outlet pages via ctx.pageLink), Title (sheet Author title, only when it lines up 1:1 or there is one author), stories, last story + headline, top issues, bills, tone avg + label, negative count, and Languages (when not English only). Below that: the shared chart and the Clips-style list. Nothing links to #clips.
- Bill numbers on the page go through ctx.billLink(bill, {date: reporter's latest story on that bill}). Until the integrator adds it, they render as <a data-bill data-date>.
- legacy(): author found → that page (an issue adds the page's topic filter); author not found → q=<name>; issue → iss=<issue>; win dropped by the framework.
- Data: page data only (ctx.D, tab-common). No reporters_data.py, no block.
- Decisions: tone column sorts most negative first, with unrated last. Top issues skip Unassigned. Month/year-precision stories are included (Pitch dropped them).
- Test: MOD=reporters harness, 146/146 (73 per viewport, 1400 and 390). Counts, tone averages, facet option counts, the combined filter, chart per year and header facts are recomputed in Node from srv/blocks.
